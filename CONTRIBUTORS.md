# 贡献者 / Contributors

LATX 感谢每一位贡献者。项目经历了两个发展阶段：2021 年至 2024 年在龙芯内部
开发，2025 年 3 月开源。开源时近两千次内部提交被合并为一次提交，因此内部
阶段的贡献无法从公开提交记录中考证，本文件按贡献领域记录该阶段的主要贡献者；
开源后的贡献以 GitHub 提交记录和 Contributors 页面为准。

LATX thanks every contributor. The project was developed internally at
Loongson from 2021 to 2024 and open-sourced in March 2025. Because nearly
two thousand internal commits were squashed into a single commit at
open-sourcing, internal-phase contributions cannot be verified from the
public commit history; this file records the major contributors of that
phase by contribution area. Post-open-source contributions are tracked by
the GitHub commit history and Contributors page.
