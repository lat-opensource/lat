# AOT v2 M10 AI 使用记录

- 使用范围：代码调查、正式 fixture 恢复、诊断设计、实现、3a6000 构建与测试、
  AgentsFlow 证据整理和文档更新。
- 人工确定的关键要求：后续调试只在 `3a6000`，不在 `3a6000-25g`；先解决混合
  缓存正确性，再处理源码唯一来源、统一安装和 cache 单写者。
- 诊断限制：没有当前 HEAD 的可重复失败，不提交猜测性运行时修复；旧环境结果
  只能用来构造对照，不能替代当前机器的原始命令、退出码和 stderr。
- 验证要求：所有结论必须来自当前构建、真实 fixture、原始日志、二进制/模块身份
  或可重复测试；AI 生成的代码和分析不能代替 3a6000 回归。
- 数据限制：不修改用户默认 AOT cache，不清理其他任务的构建、进程或测试产物；
  本任务使用独立目录和 socket。
