# AOT v2 M8 AI 使用记录

- 使用范围：代码调查、测试设计、实现、远端构建与测试、性能数据分析、
  AgentsFlow 证据整理。
- 人工确定的关键要求：动态文件 ELF 执行路径覆盖率 100%；vDSO 和匿名 JIT
  单独统计；固定动态套件为现有动态测试加 Bash；静态 SPEC 同机配对性能下降
  不得超过 1%。
- 验证要求：所有结论必须来自实际命令、原始日志、模块检查结果或性能样本；
  AI 生成的代码不能代替编译、回归、远端覆盖率和 SPEC 证据。
- 限制：不修改用户的 `~/.cache/latx`，不运行 SPEC ref，不把未执行代码的
  静态镜像占比冒充运行时覆盖率。
